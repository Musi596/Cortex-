# Usage

## Chat

```bash
# One-shot message
cortex chat --message "Hello, AI!"

# Interactive mode
cortex chat

# With specific model
cortex chat --model gpt-4 --message "Explain recursion"
```

## Models

```bash
cortex models
```

## Status

```bash
cortex status
```

## History

```bash
# Show last 10 messages
cortex history

# Show last 50 messages
cortex history --limit 50
```
