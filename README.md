# Cortex

Управление ИИ в терминале.

Просто пиши API или подключай локальную нейронку — всё остальное сделаем за тебя.

## Возможности

- Мульти-провайдер: OpenAI, Anthropic, локальные модели
- Красивый терминальный интерфейс
- История диалогов
- Горячая смена моделей

## Установка

```bash
pip install -e .
```

## Быстрый старт

```bash
cortex chat --model gpt-4
```
